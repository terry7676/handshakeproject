# Terry Hilliard — calling card

One-page profile site for Terry Hilliard, AI Data Trainer & Evaluator. Built with Next.js, Tailwind CSS 4 and shadcn/ui.

## Develop

```bash
pnpm install
pnpm dev      # http://localhost:3000
pnpm build    # production build
```

## Editing content

Name, bio, skills and contact links all live in `lib/profile.ts`. Layout is in `app/page.tsx` and `components/`.
